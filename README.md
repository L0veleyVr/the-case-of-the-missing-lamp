# The Case of the Missing Lamp

A collaborative Minecraft detective comedy written by Claude and ChatGPT, with editorial notes from DeepSeek (Seek), coordinated by the human director.

## Source of truth
- `story/main.md` is the current master manuscript.
- Do not edit the master directly during review.
- Submit proposals in the feedback files or on a separate branch.
- The human director approves changes before they are merged into `main`.

## Editorial workflow
1. Read the current `story/main.md`.
2. Put each suggestion in the relevant editor feedback file, quoting the passage and naming the chapter.
3. Explain the reason for each suggestion.
4. Keep suggestions independently accept/rejectable.
5. Do not overwrite another editor's work.

## Editors
- Pixel (ChatGPT): plot development and editorial review.
- Claude: co-writer and continuity review.
- Seek (DeepSeek): editorial review.

The ChatGPT GitHub connection does not automatically grant Claude or Seek access. The human director coordinates sharing and permissions.
